# 03 – Evaluation and Reranking

`03_evaluation_and_reranking.ipynb` measures how well the RAG system from Notebook 2 actually works. It builds a test set, compares seven retrieval strategies, double-checks the scoring with an LLM judge, and measures end-to-end answer accuracy.

## Headline results

| | Baseline (Notebook 2) | Best |
|---|---|---|
| Retrieval Hit@5 (gold page) | 0.73 | **0.82** (hybrid) / 0.86 (rerank) |
| Retrieval Hit@5 (LLM-judged) | 0.82 | **0.92** (hybrid) |
| Answer accuracy | 76.5% | **80.4%** (hybrid) |
| Out-of-scope questions refused | 5/5 | **5/5** |

Fiscal-year filtering alone took Hit@5 from **0.53 to 0.73**, the biggest single gain.

## Test set

56 questions, built with a fixed random seed:

| Type | Count | Source |
|---|---|---|
| Table | 24 | Generated by Gemini from a sampled table |
| Text | 16 | Generated from a sampled text chunk |
| Chart | 10 | Generated from a sampled chart summary |
| Hand-written | 4 | The Notebook 2 test questions |
| Unanswerable | 5 | e.g. "Who is the CEO of Google?", "What was Infosys's revenue in FY2024?" |

Each answerable question has a reference answer and a gold report + page. 3 ambiguous generated questions were dropped.

## Retrieval comparison

All variants use fiscal-year and company filters except #1.

| Variant | Hit@1 | Hit@3 | Hit@5 | Hit@10 | MRR |
|---|---|---|---|---|---|
| 1. Dense, no filters | 0.24 | 0.49 | 0.53 | 0.67 | 0.37 |
| 2. Dense + filters (Notebook 2) | 0.43 | 0.59 | 0.73 | 0.86 | 0.55 |
| 3. BM25 + filters | 0.51 | 0.67 | 0.78 | 0.86 | 0.62 |
| 4. Hybrid (RRF) | 0.59 | 0.71 | 0.82 | 0.86 | 0.67 |
| 5. Dense + rerank | 0.59 | **0.82** | **0.86** | 0.86 | **0.69** |
| 6. Hybrid + rerank | 0.55 | 0.77 | **0.86** | **0.90** | 0.66 |
| 7. Dense + rerank (fused) | 0.55 | 0.73 | 0.84 | 0.88 | 0.67 |

- **BM25:** keyword search with a tokenizer that keeps numbers like `1,237.40` and `fy24` whole.
- **Hybrid:** dense and BM25 results merged with Reciprocal Rank Fusion.
- **Rerank:** `BAAI/bge-reranker-base` cross-encoder over the top 20 candidates. Scores are cached.

**Keyword search beat embeddings on tables** (Hit@5 0.90 vs 0.76), because table questions hinge on exact terms and numbers.

## LLM-judged relevance

Gold-page scoring misses correct answers found elsewhere (the same figure often appears on several pages). Gemini judged each of the top 5 passages: *does this actually answer the question?* Under judged scoring, hybrid search reached Hit@5 **0.92**.

The judge was itself checked: it rejected 24 gold passages and accepted 44 non-gold ones, so judged scores are a second opinion, not ground truth.

## Answer accuracy

Answers for all 56 questions were generated with the Notebook 2 prompt, then graded against the reference answers by Gemini.

| Retrieval | Correct | Correct + partial | Wrongly refused | Unanswerable refused |
|---|---|---|---|---|
| Dense + filters | 76.5% | 78.4% | 13.7% | 5/5 |
| Hybrid (RRF) | **80.4%** | **80.4%** | **11.8%** | 5/5 |

## Refusal threshold

The reranker's top score separates answerable from unanswerable questions well: median 0.999 for answerable vs 0.47 for unanswerable. At a threshold of 0.8, the system would refuse 5/5 unanswerable questions and wrongly refuse 2/51 answerable ones, *before* calling the LLM.

## Error analysis

- **Same page, wrong year.** For the gross NPA question, page 148 of the FY2024 report holds both the FY24 table and the prior-year table. The reranker ranked the prior-year table higher (0.73 vs 0.12). Page-level scoring counts this as a hit, so it can't catch this kind of mistake.
- **Remaining misses** (7 for the best variant) include near-misses on an adjacent page (p.260 vs p.261, p.129 vs p.128) and two chart questions where text or tables outranked the chart.

## Caveats

- Test questions were generated by an LLM from the indexed content, which may favour retrieval that matches their wording.
- The unanswerable set has only 5 questions, and the refusal threshold was tuned on the same set.
- The accuracy gain from hybrid retrieval is 2 questions out of 51.
- Answers were generated with `gemini-3.5-flash-lite`, a smaller model than the Notebook 2 demo (`gemini-3.8-flash`).

## Next steps

- **Rerank wrongly refused questions.** About 12% of answerable questions were refused, so this is the biggest accuracy gain left.
- **Score by table, not page,** to catch same-page, wrong-year errors.
- **Grow the unanswerable set** and validate the refusal threshold on held-out questions.

## Running it

**Input:** the ChromaDB index and `docstore.json` from Notebook 2, in `MyDrive/annual-report-rag/`.

1. Open the notebook in Colab with a **T4 GPU** runtime (CPU works, but reranking is about 10x slower).
2. Add `GEMINI_API_KEY` to Colab Secrets.
3. Run all cells. Generated questions, reranker scores, relevance judgments, answers and grades are cached in `eval/`, so reruns make no new API calls.

**Outputs saved to `eval/`:** `golden.csv`, `retrieval_results.csv`, `ablation_retrieval.csv`, `answer_accuracy.csv`

**Libraries:** `google-genai`, `sentence-transformers` (bge-small embeddings, bge-reranker-base), `chromadb`, `rank_bm25`, `pandas`
